# Contributing

See [Ryo’s review and contribution guide](START-HERE-RYO.md) for context, local preview instructions and the fork → branch → pull request workflow.

Please submit design changes through a pull request to `main`, with desktop/mobile screenshots and a short explanation. Preserve existing content unless a copy change is explicitly identified. Keep credentials, local configuration and unrelated private messages out of commits.

The live website is deployed separately. Repository contributions do not automatically publish changes.
